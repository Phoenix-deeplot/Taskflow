# 修改记录

> 本文件记录**每一次**对本项目文档、代码和数据库结构的修改，以及审查中发现的问题。追加在对应轮次末尾，不改写旧条目；更正旧结论时新增一条并写明“更正”。
> 每条包含：编号、类型、执行方、内容、涉及文件、验证、状态。测试数量以写入时为准。

## 一、记录规则

1. 谁改谁记：新增或修改文件、迁移、测试、文档，都要在“修改明细”里加一行；只读审查发现的问题记入“发现与更正”。
2. 数据库结构变化必须写明**对已有数据的影响**和**回退办法**。
3. 行为变化（不只是新增）必须写明**原因**和**被替换的旧行为**。
4. 提交到 git 是另一回事：本记录不代替提交信息。
